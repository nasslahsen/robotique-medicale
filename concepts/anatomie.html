Anatomie d'un robot

Le vocabulaire de base pour décrire un bras : base, segment, articulation, axe, poignet, effecteur. Et les deux façons dont une articulation peut bouger.

Intuition

Comparez le robot à votre bras : les os sont rigides (ce sont les segments), les articulations les relient et permettent de bouger (épaule, coude, poignet), et la main tient l'outil (l'effecteur). Chaque articulation ne fait qu'un mouvement simple, autour ou le long d'un axe. Toute la suite du cours décrit un robot comme une succession de ces éléments.

Formalisation

TermeDéfinition du cours
Basepartie fixe qui supporte le robot
Segmentélément mécanique rigide reliant deux articulations
Articulationliaison mécanique mobile entre deux segments, permettant un mouvement relatif
Axedirection autour de laquelle une articulation tourne, ou le long de laquelle elle se déplace ; il correspond à un mouvement indépendant commandé par le robot
Poignetensemble de plusieurs articulations terminales assurant principalement l'orientation de l'effecteur
Effecteur (organe terminal)outil fixé à l'extrémité du robot pour réaliser la tâche

Relation entre les notions : l'articulation (relie deux segments) définit l'axe (direction du mouvement), qui produit le mouvement (déplacement relatif). Lecture d'une chaîne robotique : un robot est une succession de segments reliés par des articulations,

\[ \text{Segment}_i \;\rightarrow\; \text{Articulation}_i \;\rightarrow\; \text{Segment}_{i+1} \]

Deux types d'articulations

Une articulation rotoïde (R) produit un mouvement angulaire autour de son axe de rotation ; sa variable est un angle \(\theta_i\). Une articulation prismatique (P) produit un mouvement linéaire le long de son axe de translation ; sa variable est une distance \(d_i\).

Exemples selon la nature du mouvement : robot articulé R-R-R-R-R-R (rotations successives), robot cartésien P-P-P (translations selon X, Y, Z), robot SCARA ou cylindrique R + P (rotation et translation combinées). Le type de mouvement dépend de la nature des articulations utilisées.

Exemple

Le choix de l'effecteur dépend de la tâche, de la pièce et du procédé. Effecteurs industriels : pince de préhension, ventouse, torche de soudage, pistolet de peinture, outil de vissage, caméra d'inspection. En médecine, l'effecteur est un instrument adapté à un geste clinique : pince chirurgicale (préhension de tissus), ciseaux (section contrôlée), porte-aiguille (suture), caméra endoscopique (visualisation), instrument de biopsie (prélèvement), électrode de coagulation. Ces outils sont interchangeables au poignet robotique.

Formules clés

\[ \text{Segment}_i \rightarrow \text{Articulation}_i \rightarrow \text{Segment}_{i+1} \qquad \text{R : variable } \theta_i \qquad \text{P : variable } d_i \]

Questions

  1. Quelle est la différence entre une articulation et un axe ?
    Voir la réponseL'articulation est la liaison mécanique mobile entre deux segments ; l'axe est la direction autour de laquelle elle tourne (R) ou le long de laquelle elle coulisse (P).
  2. À quoi sert principalement le poignet ?
    Voir la réponseÀ orienter l'effecteur : c'est l'ensemble des articulations terminales.
  3. Quelle variable décrit une articulation prismatique ? une articulation rotoïde ?
    Voir la réponseUne distance \(d_i\) (prismatique) ; un angle \(\theta_i\) (rotoïde).
  4. Citez trois effecteurs médicaux et leur geste.
    Voir la réponsePince chirurgicale (préhension de tissus), porte-aiguille (suture), caméra endoscopique (visualisation) ; aussi ciseaux, instrument de biopsie, électrode de coagulation.
