Le cours

Une page par notion, pour relire : intuition, figure à manipuler, formules et exemple chiffré. Mêmes chapitres que le jeu.

Notations : repères \(R_0 = (O_0, \vec{x}_0, \vec{y}_0, \vec{z}_0)\), matrices de rotation \(R^{0,1}\), angles d'Euler ZYX \(R^{(0,s)} = R_z(\alpha)\,R_y(\beta)\,R_x(\gamma)\), matrices homogènes \(T^{0,s}\). Les bases de mathématiques (chapitre 0) se travaillent dans le jeu.
