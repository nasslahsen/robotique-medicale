Base de données et SGBD

Chaque service gardait son fichier Excel des patients : quatre adresses différentes pour la même personne. Une base de données règle ce désordre, à condition d'être bien gérée.

Intuition

Une base de données rassemble les données en un seul endroit structuré, que plusieurs personnes utilisent en même temps. Le SGBD est le logiciel qui la crée et la fait vivre : il définit sa structure, laisse manipuler les données, contrôle qui y accède, garde les données justes et disponibles.

Formalisation

Base de données : collection de données structurées, enregistrée sur la mémoire de stockage, accessible simultanément par plusieurs utilisateurs. Avantages : indépendance de logiciels d'applications particulières ; cohérence ; redondance minimale ; accessibilité simultanée par plusieurs utilisateurs. Méthodes de modélisation : UML, Merise.

Système de gestion de base de données (SGBD) : logiciel (ou ensemble de logiciels) capable d'assurer la création et l'utilisation des bases de données. Exemples : Oracle, SQL Server, MySQL, PostgreSQL, DB2...

Exemple ajouté.

Deux infirmières modifient la même prescription au même instant : un verrou garde la donnée cohérente (intégrité). Le disque du serveur lâche : la copie répliquée prend le relais (disponibilité). Un stagiaire termine son stage : DENY lui retire l'accès (LCD).

Formules clés

Base de données : indépendance, cohérence, redondance minimale, accès simultané.

SGBD : LDD (CREATE, ALTER), LMD (INSERT, UPDATE), LCD (GRANT, DENY), intégrité, disponibilité.
