Exemple 2 : Blood Pressure Monitor

Un tensiomètre électronique gonfle un brassard, le dégonfle en mesurant, affiche le résultat, émet un bip et peut envoyer la mesure par USB. Presque tout cela tient dans une seule puce. Comment s'organise-t-elle ?

Intuition

Suis le parcours d'une mesure. Le capteur de pression donne une tension minuscule : on l'amplifie, on ajuste son gain, on la convertit en nombres, on filtre ces nombres, et le MCU les lit. Dans l'autre sens, le MCU commande : la pompe pour gonfler, la valve pour dégonfler, l'écran pour afficher, le haut-parleur pour le bip.

Le cours montre ce tensiomètre construit autour d'un Programmable System on Chip : un circuit qui contient le processeur et la plupart de ses périphériques. Hors de la puce restent les organes physiques : capteur, pompe, valve, écran, haut-parleur, batterie.

Formalisation

CheminBlocs du schéma
MesurePressure Sensor → AMP → PGA → ADC → Signal Filtering → MCU
GonflageMCU → PWM Motor Control → Motor Driving Transistors → Rolling Pump → Air Chamber
DégonflageMCU → PWM Valve Control → Relay Valve (sur la chambre à air)
SonMCU → DAC → Band Pass Filter → Mono Speaker
InterfaceMechanical or Touch Sensing → CapSense → MCU ; MCU → LCD Driver → LCD Display
CommunicationMCU → Made For iPod, MCU → USB
ÉnergieBattery → Power Management

La pression du brassard arrive au capteur par un tuyau relié à la chambre à air. AMP est un amplificateur, PGA un amplificateur à gain programmable (Programmable Gain Amplifier) : le MCU règle son gain pour que le signal occupe bien la plage de l'ADC. L'ADC convertit une tension en nombre ; le DAC fait l'inverse. Le PWM (modulation de largeur d'impulsion) commande la puissance moyenne envoyée au moteur ou à la valve, à travers des transistors qui fournissent le courant que la puce ne peut pas donner.

La légende du schéma classe les blocs en familles : CPU, ADC/DAC, Amplifier/Comparator, Filters, User Interface, Communication, Digital Functions, Memory, System.

Exemple

Exemple ajouté : un cycle de mesure, bloc par bloc (le déroulé suit le principe général d'un tensiomètre à brassard).

  1. L'utilisateur appuie sur la touche : CapSense prévient le MCU.
  2. Gonflage : le MCU règle le rapport cyclique du PWM Motor Control ; la pompe remplit la chambre à air.
  3. Dégonflage et mesure : le PWM Valve Control ouvre la valve peu à peu ; pendant ce temps, la chaîne AMP, PGA, ADC, filtrage fournit la pression au MCU, qui en déduit la tension artérielle.
  4. Affichage : le MCU écrit le résultat par le LCD Driver.
  5. Bip : le MCU envoie des nombres au DAC, filtrés par le passe-bande, vers le haut-parleur.
  6. Transmission éventuelle par USB.

Formules clés

Mesure : capteur → AMP → PGA → ADC → filtrage → MCU. Commande : MCU → PWM → transistors → pompe ou valve. Son : MCU → DAC → passe-bande → haut-parleur. ADC : analogique vers numérique ; DAC : numérique vers analogique.
