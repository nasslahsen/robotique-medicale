CISC et RISC

Deux processeurs font la même multiplication. L'un le fait avec une seule instruction compliquée, l'autre avec quatre instructions toutes simples. Lequel choisir pour un appareil embarqué, et qu'est-ce que cela change à la puce ?

Intuition

Le jeu d'instructions, c'est le vocabulaire que comprend le processeur. Un vocabulaire riche (CISC) permet de dire beaucoup en peu de mots : une seule instruction va chercher deux nombres en mémoire, les multiplie et range le résultat. Mais chaque mot est long à exécuter, et le processeur doit contenir de quoi comprendre tous ces mots compliqués.

Un vocabulaire réduit (RISC) n'a que des mots courts : charger, calculer, ranger. Il faut plus de mots pour la même phrase, mais chacun s'exécute en un cycle, et la puce peut consacrer ses transistors à des registres. Les AVR et les ARM des pages suivantes sont des processeurs RISC.

Formalisation

CISC : Complex Instruction Set Computer. RISC : Reduced Instruction Set Computer. Le tableau du cours (diapositive 10) :

CISCRISC
Emphasis on hardwareEmphasis on software
Includes multi-clock complex instructionsSingle-clock, reduced instruction only
Memory-to-memory : "LOAD" and "STORE" incorporated in instructionsRegister to register : "LOAD" and "STORE" are independent instructions
Small code sizes, high cycles per secondLow cycles per second, large code sizes
Transistors used for storing complex instructionsSpends more transistors on memory registers

En français : le CISC met la complexité dans le matériel, avec des instructions qui durent plusieurs cycles et vont d'une case mémoire à une autre ; son code est court. Le RISC met la complexité dans le logiciel (le compilateur), avec des instructions d'un cycle qui travaillent de registre à registre, LOAD et STORE étant des instructions à part ; son code est plus long.

Exemple

Exemple ajouté.

Multiplier le nombre de la case mémoire 2:3 par celui de la case 5:2 et ranger le résultat en 2:3.

CISCRISC
MULT 2:3, 5:2 (une instruction, plusieurs cycles)LOAD A, 2:3
LOAD B, 5:2
PROD A, B
STORE 2:3, A
(quatre instructions d'un cycle)

Le CISC a le code le plus court (1 instruction contre 4) ; le RISC ne touche la mémoire qu'avec LOAD et STORE, et PROD ne travaille que sur les registres A et B.

Formules clés

CISC : complexité dans le matériel, instructions multi-cycles, mémoire à mémoire, code court. RISC : complexité dans le logiciel, instructions d'un cycle, registre à registre (LOAD et STORE séparés), code long, plus de registres.
