Les parcours à essayer

  1. Continuer : tableau de bord → Continuer → la leçon → Continuer → fin de leçon → Leçon suivante.
  2. Réviser avant un examen : module → onglet Réviser → Examen blanc → Commencer → Revoir mes erreurs.
  3. Relire une notion : Réviser → Toutes les leçons → une leçon ; ou, dans une leçon, Relire en haut à droite.
  4. Ouvrir un chapitre directement : carte du module → touche n'importe quel bloc.
  5. Un cours ajouté : module avec la ligne « Nouveau ».
  6. Fil d'Ariane long : leçon d'Architecture hospitalière, les éléments du milieu sont raccourcis.
