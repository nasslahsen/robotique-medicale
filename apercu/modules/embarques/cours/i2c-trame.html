Chronogramme I2C

Sur les deux fils de l'I2C, tous les circuits entendent tout. Comment une EEPROM sait-elle qu'un message commence, qu'il lui est destiné, et quand il se termine ?

Intuition

Un message I2C ressemble à un appel au téléphone dans une salle pleine. On attire l'attention (START), on dit le nom de la personne (l'adresse) et si l'on veut parler ou écouter (le bit R/W). La personne répond « oui » (ACK). Ensuite on échange des octets, chacun suivi d'un « reçu » (ACK). À la fin, on raccroche (STOP), et la ligne est libre pour les autres.

Le maître donne le rythme sur SCL : une impulsion par bit. Chaque octet prend 8 impulsions, plus une 9e pour l'accusé de réception.

Formalisation

Chronogramme du cours, de gauche à droite :

ChampImpulsions SCLRôle
S (START condition)début du message : SDA passe de 1 à 0 pendant que SCL est à 1
7-Bit ADDRESS1 à 7adresse de l'esclave
\(R/\overline{W}\)8sens : 1 lecture, 0 écriture (la barre est sur le W)
ACK9l'esclave accuse réception
8-Bit DATA1 à 8un octet de données
ACK9accusé de réception de l'octet
8-Bit DATA1 à 8octet suivant
ACK/NACK9accusé, ou non-accusé pour finir
P (STOP condition)fin du message : SDA passe de 0 à 1 pendant que SCL est à 1

Compléments utiles, non écrits sur la diapositive : pendant les données, SDA ne change que lorsque SCL est à 0 ; un ACK est un 0 placé sur SDA par le récepteur (le 0 est dominant), un NACK laisse SDA à 1 ; les bits partent du poids fort au poids faible.

Exemple

Exemple ajouté.

Un MCU écrit deux octets dans une EEPROM : S, adresse sur 7 bits, \(R/\overline{W} = 0\), ACK, octet 1, ACK, octet 2, ACK/NACK, P. Sur SCL : \(3 \times 9 = 27\) impulsions entre START et STOP. Avec 7 bits, il existe \(2^7 = 128\) combinaisons d'adresse. Pour lire un thermomètre d'adresse 1010111, le premier octet envoyé est 1010111 suivi de \(R/\overline{W} = 1\) : 10101111.

Formules clés

\[ N_{SCL} = 9 \times N_{octets} \qquad N_{adresses} = 2^7 = 128 \qquad R/\overline{W} = 1 : \text{lecture},\ 0 : \text{écriture} \]

S, adresse 7 bits, R/W, ACK, données 8 bits, ACK, …, ACK/NACK, P.
